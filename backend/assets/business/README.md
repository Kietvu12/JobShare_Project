# Business landing — brochure PDF

Place `JobShare_Business_Service_Guide.pdf` in this folder for the document-download API (`POST /api/public/business/document-download`).

Copy from the frontend static file if needed:

`frontend/public/documents/JobShare_Business_Service_Guide.pdf`

Or set on the server:

`BUSINESS_DOCUMENT_PDF_PATH=/absolute/path/to/JobShare_Business_Service_Guide.pdf`
